# Report visuals

The PNG and SVG files here are used by the Macrova BCA report's Appendix C.

- `architecture`, `auth-flow`, `domain-model`, `calculation-flow`, and `ai-sequence` are original diagrams based on the checked-in application code.
- `signup`, `login`, `dashboard`, `progress`, `meal-suggestions`, and `plan-form` are screenshots captured from the running Angular application. Guest pages show their actual forms. Authenticated pages were rendered with synthetic mocked API responses because this repository does not include a configured test database or live account. The meal cards use a mocked suggestion response; they are not presented as live OpenRouter output.

All displayed values and identities in the authenticated screenshots are illustrative and are not real user or health data.
